App Store Review Guideline 5.1.1 Verified On-Device Privacy

Kebijakan Privasi / Privacy Policy

Aplikasi: Store Audit Cam • Pengembang: Ridwan Saputra • Berlaku Sejak: Oktober 2026 / October 2026

1. Identitas Aplikasi & Pengembang

Kebijakan Privasi ini mengatur penggunaan aplikasi seluler Store Audit Cam ("Aplikasi") yang dikembangkan dan dikelola secara independen oleh Ridwan Saputra ("Pengembang").

Dokumen ini dibuat untuk memberikan transparansi penuh kepada pengguna mengenai hak privasi dan bagaimana izin perangkat diproses secara aman sesuai dengan standar ketentuan Apple App Store Review Guidelines (Guideline 5.1.1).

2. Data & Izin Perangkat yang Diakses

Untuk menjalankan fungsinya sebagai sarana dokumentasi operasional toko, Aplikasi memerlukan beberapa izin fungsional perangkat berikut. Setiap izin digunakan secara spesifik hanya saat pengguna aktif menggunakan fitur terkait:

📷 Kamera NSCameraUsageDescription

Digunakan murni untuk mengambil foto dan merekam video bukti audit kebersihan dan operasional toko secara langsung oleh pengguna.

🎤 Mikrofon NSMicrophoneUsageDescription

Digunakan hanya untuk merekam audio bersamaan saat pengguna merekam video bukti dokumentasi di dalam aplikasi.

📍 Lokasi / GPS NSLocationWhenInUseUsageDescription

Digunakan saat aplikasi aktif untuk mengambil koordinat lintang/bujur dan nama tempat guna disematkan sebagai teks watermark otomatis pada foto hasil jepretan sebagai validasi lokasi audit.

🖼️ Galeri Foto & Media NSPhotoLibraryUsageDescription & NSPhotoLibraryAddUsageDescription

Digunakan untuk menyimpan foto/video hasil audit ke galeri perangkat pengguna, serta memilih foto dari galeri untuk fitur kolase dokumentasi atau logo kustom.

3. Cara Penyimpanan Data (Penyimpanan Lokal / Non-Cloud)

🔒 100% On-Device Storage (Pemrosesan Lokal)

Semua foto, video, dan koordinat lokasi disimpan secara lokal di perangkat pengguna. Aplikasi tidak mengunggah, mencadangkan, mentransmisikan, atau menyinkronkan foto/video audit ke server internal mana pun.

Seluruh proses penyematan stempel digital (watermarking) foto dan kompresi media dieksekusi langsung oleh prosesor perangkat Anda secara lokal (*offline-capable*).

4. Tidak Ada Pelacakan Pihak Ketiga (No Tracking & No Ads)

Kami menjunjung tinggi integritas data dan privasi pengguna dalam lingkungan kerja operasional:

  • Bebas Iklan & Pelacak: Aplikasi tidak menggunakan SDK pelacak iklan (ad tracker) pihak ketiga mana pun.
  • Tanpa IDFA: Aplikasi tidak meminta atau mengakses Apple Advertising Identifier (IDFA).
  • Tanpa Penjualan Data: Kami tidak pernah menjual, menyewakan, atau membagikan data identitas/lokasi pengguna ke pialang data (*data brokers*) atau entitas komersial luar.

5. Privasi Anak-Anak (Children’s Privacy)

Aplikasi Store Audit Cam dirancang secara khusus untuk keperluan pekerjaan operasional dan audit ritel profesional. Aplikasi tidak ditujukan untuk anak-anak di bawah umur 13/17 tahun dan tidak secara sengaja mengumpulkan informasi data pribadi dari anak-anak.

6. Hak Pengguna (User Control & Data Rights)

Pengguna memiliki kendali penuh atas izin perangkat dan file dokumentasi mereka:

  • Pengaturan Izin Kapan Saja: Anda dapat mencabut atau mengaktifkan kembali izin Kamera, Mikrofon, atau Lokasi kapan pun melalui menu Pengaturan iOS (Settings > Privacy & Security).
  • Penghapusan File Mandiri: Seluruh foto dan video hasil audit dapat dihapus secara permanen kapan saja langsung dari aplikasi Galeri Foto bawaan perangkat Anda.
